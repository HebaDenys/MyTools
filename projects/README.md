# Independent projects

Place a larger, independently runnable project under projects/<project-id> only
when it actually exists. Give it its own README, tests, runtime/build instructions
and explicit reference to the root LICENSE and COMMERCIAL.md. Do not create
empty directories or claim roadmap ideas are implemented.

A future Java/Spring service, mobile application or desktop program need not
share the browser toolbox runtime. Reusable browser logic belongs in packages;
small completed tools can be added to apps/toolbox.

Original code inherits the same rule: free private personal use; paid business
and professional use. Preserve any identified third-party licenses separately.
